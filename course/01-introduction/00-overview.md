# Introduction

Six short lessons that give you a web page of your own, and teach you git, which saves your work. At the end you have a page with a title, a welcome line and a button, saved with git and on GitHub.

## In this chapter

- [1.1: Git introduction](01-git-introduction.md)\
  Make a project folder that git watches, and save it twice.
- [1.2: Hello, HTML and CSS](02-hello-html-css.md)\
  Write your first page, and change how it looks with CSS.
- [1.3: Git workflow](03-git-workflow.md)\
  Save the page, read what changed, and undo a mistake.
- [1.4: Colour and type](04-colour-and-type.md)\
  Choose colours, fonts and sizes, and see the page on a phone.
- [1.5: The head, the body and a button](05-head-body-button.md)\
  Add a title, an icon and a button, and read the first lines of the file.
- [1.6: GitHub](06-github.md)\
  Put your project on GitHub.

Keep the cheatsheets open while you work: [git](../reference/01-git-cheatsheet.md), [HTML](../reference/02-html-cheatsheet.md), [CSS](../reference/03-css-cheatsheet.md) and [DevTools](../reference/04-devtools-cheatsheet.md).
