# Web app course

Learn HTML, CSS and JavaScript by building a small web app, one short lesson at a time. The app is a Student Planner, with a page for your schedule, one for your homework and one for your clubs. You write every line yourself, in your own editor, and you save your work with git as you go. You do not need to have written code before. Each lesson takes 20 to 40 minutes and ends with a few tasks to try on your own, and the Reference section has short cheatsheets to keep open while you work.

## Chapters

- [Introduction](01-introduction/00-overview.md)\
  Set up your tools and build the first page of the app: a title, a welcome line and a button. You learn the git commands that save your work and put it on GitHub, the tags of an HTML page, and your first CSS rules for colour and type.
- [Classes and styles](02-classes-and-styles/00-overview.md)\
  Learn how to point a style at the right tag with classes, and how every tag is a box with space inside and outside it. At the end your first page is styled, centred in a card, and the button reacts to the mouse.
- [Layout and look](03-layout-and-look/00-overview.md)\
  Build the top bar and two more pages of the app, Schedule and Activities. You write them first with classes named for what is on the page, then notice what repeats, and write them again with a few classes for where things go, how they look and how much space they get. At the end you have a small set of layout classes of your own.
